제출 이미지 검토

사용자가 GitHub Issue로 제출한 사진을 여기서 상태별로 확인합니다. 실제 승인/반려 처리는 GitHub Issue에서 라벨을 변경하는 방식으로 진행합니다.

검토대기검토중승인반려검증완료

권장 흐름: 검토대기 → 검토중 → 승인 → 한국판 ROI/템플릿 반영 → 검증완료. 잘못된 제출은 반려 또는 수정요청으로 분류합니다.

검토 기준

  1. Shute6 항목과 한국판 화면의 역할이 같은지 확인
  2. 전체 스크린샷이면 필요한 최소 ROI를 다시 크롭
  3. 글자/아이콘이 잘리지 않았는지 확인
  4. 한국판 UI에서 재현 가능한지 확인
  5. 검증 후 verified 데이터에 반영
