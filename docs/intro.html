프로젝트 소개

이 프로젝트는 중국판 연우강호(烟雨江湖) Shute6 매크로를 한국판 낭만강호에서 사용할 수 있도록 한글화·이식하는 작업입니다.

현재는 매크로가 화면을 인식할 때 사용하는 중국판 이미지 템플릿을 한국판 UI에 맞는 이미지로 교체하는 단계입니다. 각 폴더에서 Shute6 원본 템플릿 PNG와 이미 검증된 한국판 크롭 PNG를 비교할 수 있고, 아직 한국판 이미지가 없는 항목은 직접 스크린샷을 제출해 함께 채울 수 있습니다.

중국판과 한국판의 글자·아이콘 픽셀은 서로 다르기 때문에 Shute6의 분류와 사용 맥락은 참고하되, 한국판 인식 이미지는 실제 한국판 화면에서 새로 수집·검증합니다.
