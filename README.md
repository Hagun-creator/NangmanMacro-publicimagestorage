# NangmanMacro Public Image Storage

낭만강호 자동화 프로젝트의 **한국판 이미지 수집·검수용 공개 저장소**입니다.

이 저장소의 목적은 Shute6 중국판 템플릿을 그대로 재사용하는 것이 아니라, **Shute6의 분류/용도와 1:1로 대응되는 한국판 전용 이미지 ROI와 픽셀 템플릿을 새로 구축**하는 것입니다.

## 참여 방법

1. 이미지 작업 웹페이지에서 필요한 항목을 확인합니다.
2. 낭만강호 한국판 전체 스크린샷을 준비합니다.
3. 직접 크롭하거나, 원본 스크린샷 그대로 GitHub Issue에 제출합니다.
4. 제출 시 가능한 경우 분류, 화면 해상도, 보이는 한국어 이름을 적어주세요.
5. 원본은 검수 후 최소 ROI로 크롭하고, 한국판 전용 grayscale/threshold/1-bit pixel template로 변환합니다.

## 중요 원칙

- 중국판 Shute6 픽셀 데이터와 한국판 픽셀 데이터는 별도로 관리합니다.
- 원본 전체 스크린샷을 APK에 넣지 않습니다.
- APK에는 검증된 최소 ROI 또는 압축 픽셀 템플릿만 넣습니다.
- 문파/경공/지도명처럼 한자와 한국어가 다른 텍스트는 한국판 실캡처가 필요합니다.
- 숫자/아이콘도 실제 한국판 렌더링을 우선 검증합니다.

## 제출 위치

GitHub의 **Issues → New issue → 한국판 이미지 제출**을 사용해주세요. 스크린샷은 Issue 본문의 이미지 영역에 드래그해서 첨부하면 됩니다.

## 웹페이지

GitHub Pages용 파일은 `docs/index.html`에 있습니다. Pages 활성화 후 누구나 브라우저에서 전수조사 현황, Shute6 대응 템플릿, 직접 크롭 도구를 사용할 수 있습니다.
